# MuJoCo Model Assets

This directory contains MuJoCo XML model files for the environments provided by this package.

## Source

These model files are copied from the [Gymnasium](https://github.com/Farama-Foundation/Gymnasium) project, specifically from the `gymnasium/envs/mujoco/assets/` directory.

## Model Files

The following model files are included:
- `ant.xml` - Ant environment model
- `half_cheetah.xml` - Half Cheetah environment model
- `hopper.xml` - Hopper environment model
- `walker2d.xml` - Walker2d environment model
- `humanoid.xml` - Humanoid environment model
- `swimmer.xml` - Swimmer environment model
